Práctica 6 —
Este proyecto contiene 3 programa:
Pi interactivo: Aproxima el valor de pi lanzando dardos pero ahora el usuario es libre de ingresar el número de dardos que quiere lanzar. (Actividad 1.1)
Binario interactivo: Transforma un número decimal a binario, el usuario elige el número que quiere transformar a binario. (Actividad 1.2)
corizador pines(archivo): Programa que facilita los cálculos para un préstamo y todo lo necesario, el usuario ingresa todos los valores y elige que hacer a través de un menú. (Actividad 2.1)
