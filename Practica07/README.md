## Descripción del proyecto
El proyecto consiste en un programa que considera carcterísticas de un paquete para realizar distintas acciones como detenerminar el peso que se cobrará al final o cotizar el envío, también incluye la opción de un descuento en caso de que sea un envío con un destino local o un aumento si es un paquete fragil .

---

## Comandos para compilar, ejecutar y documentar

### 1. Compilación
```bash
# javac -d bin src/Paquete.java src/CotizadorEnvio.java src/PruebaPaqueteria.java

```

### 2. Ejecución
```bash
# java -cp bin PruebaPaqueteria

```

### 3. Generación de documentación Javadoc
```bash
# javadoc -d docs -private -encoding UTF-8 src/Paquete.java

```
